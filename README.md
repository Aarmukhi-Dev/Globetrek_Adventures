# GlobeTrek Adventures 

### Travel Booking & Management Web Application

GlobeTrek Adventures is a web-based travel platform designed to bring travel packages, accommodation, transportation, and booking management together in one place.

The application provides a customer-facing website alongside dedicated staff and administrator interfaces for managing travel-related services.

## Project Overview

GlobeTrek Adventures was developed to provide a convenient way for users to explore travel services and manage their travel-related activities through a web application.

The project includes customer account functionality and administrative tools for managing packages, bookings, accommodation, transportation, staff accounts, and customer information.

##  Features

### Customer Features
- Browse available travel packages
- Explore accommodation options
- View transportation services
- Register and log in to a customer account
- Access booking-related functionality

### Staff Features
- Staff login and dashboard
- Manage travel packages
- Manage bookings
- Manage accommodation
- Manage transportation
- View customer queries

### Administrator Features
- Administrator login and dashboard
- Manage staff accounts
- Manage customer information
- View booking information

##  Run Locally

To run the project on your local machine:

### Prerequisites
- XAMPP
- PHP
- MySQL
- Web browser

### Installation

1. Clone or download this repository.

   ```bash
   git clone https://github.com/Aarmukhi-Dev/GlobeTrek-Adventures.git
   ```

2. Move the project folder into the XAMPP `htdocs` directory.

3. Start Apache and MySQL using the XAMPP Control Panel.

4. Open phpMyAdmin:

   ```text
   http://localhost/phpmyadmin/
   ```

5. Create a MySQL database for the project.

6. Import the provided SQL database file, if included in the repository.

7. Update the database connection settings in:

   ```text
   config/db.php
   ```

8. Open the website in your browser:

   ```text
   http://localhost/GlobeTrek-Adventures/
   ```
